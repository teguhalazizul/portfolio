# Portfolio — Teguh Al Azizul

Portofolio hitam-putih dibuat dengan React + Vite (animasi scroll, typing effect, kursor kustom, toggle tema gelap/terang).

## Jalankan lokal
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Edit konten di `src/data.js`. Ganti foto di `src/assets/photo.png`.
